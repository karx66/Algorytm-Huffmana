Detailed Description

Glowny plik programu do kompresji i dekompresji plikow algorytmem Huffmana.

Program konsolowy umozliwiajacy kompresje plikow tekstowych przy uzyciu algorytmu Huffmana. Obsluguje kodowanie UTF-8 oraz rozne tryby dzialania dostepne przez parametry linii polecen.

Glowna funkcja programu.

Funkcja parsuje argumenty linii polecen i wykonuje odpowiednia operacje na podstawie przekazanych flag.

Obslugiwane flagi:

  • '-e' - tryb kodowania (encode)
  • '-d' - tryb dekodowania (decode)
  • '-a' - tryb analizy (analyze)
  • '-i <plik>' - plik wejsciowy (input)
  • '-o <plik>' - plik wyjsciowy (output)
  • '-stats' - wyswietl statystyki kompresji
  • '-h' - wyswietl pomoc
