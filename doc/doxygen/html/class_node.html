Detailed Description

Abstrakcyjna klasa bazowa reprezentujaca wezel drzewa Huffmana.

Klasa stanowi interfejs dla wezlow drzewa Huffmana. Definiuje metody czysto wirtualne isLeaf() i getSymbol() ktore musza byc zaimplementowane przez klasy pochodne. Wykorzystuje polimorfizm do obslugi roznych typow wezlow.
