Detailed Description

Klasa reprezentujaca galaz drzewa Huffmana.

Galaz laczy dwa wezly potomne (lewy i prawy) i przechowuje sume ich czestotliwosci. Uzywana do budowy struktury drzewa Huffmana. Lewe dziecko odpowiada bitowi 0, prawe dziecko bitowi 1.
